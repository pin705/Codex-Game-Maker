# Support

Use GitHub issues for reproducible installation, plugin-routing, tool, gate, migration, and documentation defects. Include:

- Codex Game Maker version and Git commit;
- Codex CLI, Python, PowerShell, Godot, OS, and architecture versions;
- the exact command and sanitized output;
- whether installation was personal or URL-marketplace based;
- a minimal project or contract fixture when licensing permits.

Run `python3 plugins/codex-game-maker/scripts/cgm.py doctor --root <project>` first. Remove tokens, user paths when sensitive, signing data, store credentials, private source URLs, and player data before posting.

Game-design taste, legal approval, store certification, confidential console requirements, and irreversible publication decisions require the relevant authorized human owner. Community support does not replace legal, platform, accessibility, localization, security, or player research professionals.
