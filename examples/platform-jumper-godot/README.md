# Platform Jumper Godot

Small Godot 4 platformer MVP created through the Codex Game Maker flow.

## Run

1. Open this folder in Godot 4.
2. Run `res://scenes/main/Main.tscn`.

## Controls

- Move: Arrow keys or A/D through Godot's built-in `ui_left` and `ui_right`.
- Jump: Space/Enter through Godot's built-in `ui_accept`.
- Restart: R.

## Goal

Collect all crystals, avoid spikes, and reach the beacon at the end of the level.
