# Game Studio Marketing

Market the verified game that exists, not the imagined roadmap.

## Required Output

Create `marketing/store-manifest.json` from `../../references/templates/store-marketing-manifest.json`.

## Workflow

1. Derive positioning, audience, differentiator, price, and claims from the approved product brief and current build.
2. Verify current store specifications and content rules from official documentation for each target.
3. Produce logo, icon, capsules, screenshots, trailers/app previews, descriptions, feature/controller/accessibility disclosures, tags, and press kit.
4. Capture actual release-candidate gameplay with debug UI removed. Label cinematic or non-gameplay footage clearly.
5. Localize text-bearing assets and metadata for every marketed language.
6. Validate dimensions, formats, safe zones, readability, rights, provenance, age appropriateness, and claim-to-runtime evidence.
7. Record store review status and final human approval.

Placeholder art, outdated screenshots, unsupported features, fabricated awards/reviews, unlicensed media, missing required variants, or mismatched localization block store submission.
